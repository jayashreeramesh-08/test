# 🍎 Fruits Shop Website

## About the Project
Fruits Shop is a simple and attractive fruit shopping website developed using HTML. It provides users with an easy way to explore different fruits.

## Technologies Used
- HTML
- CSS
- JavaScript

## Features
- Attractive user interface
- Fruit product display
- Shopping cart
- Easy navigation
- User-friendly design

- `fruits.html` – Main website page
